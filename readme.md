## Projetos selecionados

### Wheater ETL Pipeline
[Ver repositório](https://github.com/samuelafonsoDev/Wheater-ETL-Pipeline)

Pipeline desenvolvido para recolher dados meteorológicos da API OpenWeather, transformá-los e armazená-los em PostgreSQL.

- **Tecnologias:** Python, Pandas, API REST, SQLAlchemy, PostgreSQL, Docker e `uv`.
- **Objetivo:** praticar um fluxo de extração, transformação e carga de dados, com preparação para análises posteriores.
- **Nota:** a orquestração com Apache Airflow é uma possibilidade de evolução futura do projeto.

### Plataforma Online de Curso de IA
[Ver repositório](https://github.com/samuelafonsoDev/Plataforma-Online-Curso-IA)

Aplicação web criada para praticar desenvolvimento de interfaces e avaliar código e prompts gerados com inteligência artificial.

- **Tecnologias:** TypeScript, Next.js, Tailwind CSS e Material UI.
- **Objetivo:** consolidar conhecimentos de desenvolvimento web num projeto prático.

### Fundamentos de Engenharia de Dados — ETL
[Ver repositório](https://github.com/samuelafonsoDev/Fundamentos-Eng-Dados-ETL)

Projeto de estudo que trabalha dados CSV, limpeza e transformação com Pandas e carregamento em PostgreSQL.

- **Tecnologias:** Python, Pandas, Jupyter Notebook e PostgreSQL.
- **Objetivo:** praticar as etapas de ETL, incluindo tratamento de valores ausentes, padronização e remoção de duplicados.
